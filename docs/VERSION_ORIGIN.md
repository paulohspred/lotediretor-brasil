# Origem da versão v6

- **v1** deriva byte a byte do código da `LoteDiretor_SaaS_Foundation_v0.1` preservada no backup, acrescida apenas de arquivos de auditoria/versão/blueprint.
- **v2–v6** são snapshots cumulativos da nova linha canônica. Cada número foi atribuído somente depois que o marco correspondente foi incorporado ao código.
- Esta nomenclatura não afirma que os bytes da antiga árvore `Integrated_v0.6` foram recuperados. A árvore antiga foi perdida; a linha atual recompõe as funções documentadas a partir da v1 preservada.

# Semântica das fontes rurais

| Fonte | Natureza no LoteDiretor | Não inferir automaticamente |
|---|---|---|
| CAR/SICAR | ambiental, declaratório | domínio, posse ou regularidade ambiental definitiva |
| SNCR/CCIR | cadastral fundiário | domínio registral |
| SIGEF | certificação do georreferenciamento | titularidade |
| CIB/CAFIR | fiscal/cadastral | domínio registral |
| Matrícula | referência registral autorizada | equivalência automática com cadastro fiscal/CAR |
| IBAMA Embargo | restrição administrativa espacial | que todo o imóvel está embargado sem medir interseção |
| PRODES/DETER | sensoriamento/monitoramento temporal | infração ou autoria |
| SICOR | crédito rural | domínio ou situação cadastral fundiária |

Conflitos permanecem visíveis e devem ser resolvidos por evidência/revisão; o sistema não escolhe silenciosamente a fonte conveniente.
